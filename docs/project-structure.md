# Project Structure

Purpose: directory layout and what each part owns.

```text
esuyo-markdown/
├── index.html                  # App entry — sidebar, viewer, editor, settings, confirm overlays
├── package.json                # Frontend deps + scripts (dev / build / preview / tauri)
├── package-lock.json
├── vite.config.js              # Dev server (port 1420 strict), HMR, optimizeDeps prebundle
├── src/
│   ├── main.js                 # All frontend logic: scan/render/edit/save/settings (~1596 lines)
│   ├── style.css               # App chrome: sidebar, layout, menu, settings, dialogs
│   └── markdown-theme.css      # Rendered-Markdown typography only (separate from app chrome)
├── src-tauri/
│   ├── Cargo.toml              # Rust deps: tauri v2, dialog plugin, serde, walkdir, trash
│   ├── tauri.conf.json         # productName, version, identifier, devUrl, bundle targets
│   ├── tauri.microsoftstore.conf.json  # Merge config: offline WebView2 for Store bundle
│   ├── build.rs                # tauri-build hook
│   ├── capabilities/
│   │   └── default.json        # Capability allow-list (core + dialog open/save)
│   ├── icons/                  # App + Store logos (incl. StoreLogo.png, Square*Logo.png)
│   ├── msix/
│   │   └── AppxManifest.template.xml   # Tokenized manifest expanded by scripts/build-msix.ps1
│   └── src/
│       ├── lib.rs              # All Tauri commands + settings + scan/ignore logic
│       └── main.rs             # Thin entry → esuyo_markdown_lib::run()
├── sample/
│   └── welcome.md + 10 city .md files  # Demo folder (open via Open Folder to try the app)
├── images/
│   ├── normal-view.png / dark-mode.png / editing-mode.png
│   ├── raw-source-editing.png / welcome.png / settings.png
├── scripts/
│   └── build-msix.ps1          # Stages exe + logos, expands manifest, packs unsigned .msix
├── test/
│   └── test-table-better.html  # Manual table-editing fixture (open in browser, no runner)
├── test-editor-view.html       # Manual editor-view fixture at repo root
├── .github/workflows/publish.yml  # Version-bump → matrix build → Release → Store submit
├── PRIVACY.md                  # Privacy policy (local-only, Google Fonts exception)
├── LICENSE                     # GNU AGPL v3
└── docs/
    ├── architecture.md         # Stack + data flow (this set)
    ├── project-structure.md    # This file
    ├── development.md          # Local dev setup and workflows
    ├── build-and-deployment.md # Production builds, CI, Store submission
    ├── reference.md            # Tauri command + settings reference
    ├── ai-assistant-plan.md    # Proposal: OpenAI-compatible AI assistant (not implemented)
    └── git-sync-plan.md        # Proposal: Git clone/status/push/pull via system git (not implemented)
```

## Notes

- `dist/` (Vite output) and `src-tauri/target/` (Rust output) are git-ignored (`.gitignore:2-3`, `.gitignore:11`) and generated by builds.
- `src-tauri/Cargo.lock` exists on disk but is git-ignored (`.gitignore:12`); CI restores it from scratch.
- `src-tauri/gen/` is Tauri-generated schemas, also ignored (`.gitignore:42`).
- The two `*-plan.md` files in `docs/` are **design proposals**, not current behavior. They are preserved as-is and linked from the README for visibility.
- `test/` and `test-editor-view.html` are manual HTML fixtures — there is no automated test runner (see `docs/development.md`).
